# assets

`human.glb` — "Animated Human" by Quaternius, from poly.pizza.
Licence: Creative Commons CC0 1.0 Universal (public domain). No attribution
is required; it is here so the origin of the file is not a mystery later.

It is 1578 triangles with a standard humanoid skeleton. Its animations are
idle, walk, run, jump, punch, working and death. None of them is skating,
which is the reason it is only in the game behind a comparison toggle.
